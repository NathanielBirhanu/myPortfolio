# Natnael B. Regasa Portfolio

Personal portfolio website for Natnael B. Regasa, a Senior Odoo Developer and ERP Consultant based in Addis Ababa, Ethiopia.

## Built With

- React.js
- React Bootstrap
- CSS3
- React Router

## Profile

Natnael works on ERP implementations, Odoo custom module development, REST API integrations, third-party integrations, data migration, server deployment, system performance optimization, and AI-powered workflow automation.

## Installation

```bash
npm install
```

## Run Locally

```bash
npm start
```

Open `http://localhost:3000` in Chrome to view the site. The browser should refresh automatically when you save changes.

## Testing

Run the test suite once:

```bash
npm test -- --watchAll=false
```

Run tests in watch mode while editing:

```bash
npm test
```

Check the production build:

```bash
npm run build
```

## Customization

Most editable portfolio content lives in `src/components/`. The resume PDF used by the Resume page is `src/Assets/Natnael_B_Regasa_CV.pdf`.
